# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public issue.

- **GitHub**: use **Report a vulnerability** in the **Security** tab of this
  repository (private vulnerability reporting).
- **Email**: [engineering@devmatrix.dev](mailto:engineering@devmatrix.dev)

Include the extension version, your editor and version, and the steps to
reproduce. Please give us a reasonable time to fix the issue before
disclosing it.

## Supported versions

Security fixes are released for the latest published version of the
extension. Installed copies update automatically from the Visual Studio
Marketplace and Open VSX.
