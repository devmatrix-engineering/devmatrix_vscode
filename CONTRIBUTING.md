# Contributing

The DevMatrix extension is developed privately. This repository hosts the
extension's releases and its issue tracker; it does not contain the source
code, so pull requests cannot be accepted.

Issues are welcome:

- **Bug reports**: use the *Bug report* template, with the extension version,
  your editor and version, and the steps to reproduce.
- **Feature requests**: use the *Feature request* template and describe the
  problem you want solved.
- **Security vulnerabilities**: do not open an issue; see
  [SECURITY.md](SECURITY.md).

Please do not include DevMatrix Keys, spec contents you consider
confidential, or other secrets in an issue.
